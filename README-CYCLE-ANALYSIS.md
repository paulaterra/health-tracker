# Anàlisi avançada del cicle

Aquesta versió afegeix seguiment específic de:
- mal d'esquena i rigidesa durant els 5 dies posteriors a la regla;
- inflor, esgotament, despertars i encendre llums dormida durant els 5 dies previs;
- diarrea durant la finestra d'ovulació (±3 dies).

Els resultats apareixen al Dashboard, Patrons, Conclusions i Informes. L'app parla d'associacions observades, no de causes demostrades.
