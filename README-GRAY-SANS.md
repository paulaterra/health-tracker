# Paula Tracker — gris i sans serif

Versió basada en `paula-tracker-visual-colors` amb:

- color principal gris `#2D2D2D`;
- tipografia sans serif Inter per a títols i textos;
- paleta de colors per categories conservada;
- Supabase, PWA, informes i funcionalitats conservats.

## Prova local
Obre la carpeta amb Visual Studio Code i executa `index.html` amb Live Server.

## Publicació
Puja tot el contingut de la carpeta a la branca `main` del repositori de GitHub Pages.
