# Paula Tracker v1.4.6

## Escales 0–10 unificades

A totes les puntuacions de salut, **0 representa el millor estat i 10 el pitjor**.

S'han invertit automàticament els registres antics de:
- qualitat del son / mal descans;
- energia física / cansament físic;
- energia mental / boira mental.

La migració es marca dins de cada registre amb `scoreScaleVersion: 2`, de manera que no es torna a executar sobre les mateixes dades.
