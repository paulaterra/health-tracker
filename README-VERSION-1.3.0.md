# Paula Tracker v1.3.0

## Novetats

- Dashboard intel·ligent amb estat d'avui, destacat principal i predicció personal.
- Calendari mensual amb icones de símptomes i fitxa completa de cada dia.
- Nou apartat **El meu cos**, amb perfil personal viu.
- Nou apartat **Pregunta a la IA**, que respon localment a partir de les dades de Supabase, sense internet ni serveis d'IA externs.
- Prediccions prudents basades en patrons repetits i fases estimades del cicle.
- Informes amb dos formats: resum mèdic visual i informe complet.
- Nova interpretació: en un dia amb dades, un símptoma no registrat s'interpreta com a absent/tot OK. Son, energia i altres variables positives continuen sent desconegudes si no s'han registrat.
