# Health Track 1.6.13

## Motor de fenotip de dolor

- Nova capa transversal que analitza el comportament del dolor abans de proposar hipòtesis diagnòstiques.
- Detecta recurrència, distribució anatòmica ampla, dolor multiregional, rigidesa, coincidència amb son/fatiga i solapament amb cefalea/vertigen.
- Pot mostrar, quan les dades ho justifiquen: “Possible fenotip de dolor nociplàstic/sensibilització central. Valorar fibromiàlgia segons evolució, distribució del dolor i criteris clínics.”
- Separa sensibilització central, fibromiàlgia, component musculoesquelètic/miofascial i son com a possible amplificador.
- Les conclusions són condicionals: no apareixen per defecte ni perquè s’hagi introduït manualment una hipòtesi.
- La mateixa anàlisi s’utilitza a Conclusions i als informes PDF.

L'app continua sent una eina d'autoregistre i detecció de patrons, no una eina diagnòstica.
