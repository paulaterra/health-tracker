# Paula Tracker v1.4.15

## Anàlisi intel·ligent amb període seleccionable

- Selector de 30, 60 o 90 dies al Dashboard.
- L’anàlisi per apartats es recalcula amb les dades del període escollit.
- Per defecte s’analitzen els últims 30 dies.
- El període i el nombre de dies analitzats queden visibles a la mateixa secció.
