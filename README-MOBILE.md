# Paula Tracker — navegació mòbil superior

Versió funcional amb Supabase i PWA. Al mòbil manté tots els apartats de registre en una barra superior horitzontal optimitzada, i una barra inferior fixa per Inici, Registres, Anàlisi, Informes i Més.

## Ajust mòbil — barra superior eliminada

S’ha eliminat exclusivament la barra horitzontal d’accessos directes als registres en la interfície mòbil. Els registres continuen accessibles des del botó **Registres (+)** de la barra inferior; la versió d’escriptori, Supabase, la PWA i la resta de funcionalitats no canvien.
