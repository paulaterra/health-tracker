# Paula Tracker · v1.6.0

## Novetats principals

- Nou registre opcional de finestra fèrtil i ovulació, amb font de la dada (manual, Clue, LH, temperatura basal o altres).
- Estimació automàtica de la finestra fèrtil i l’ovulació quan hi ha prou historial; sempre es marca com a estimació.
- La dada manual té prioritat sobre l’estimació automàtica.
- El calendari detallat mostra una banda per a finestra fèrtil i menstruació.
- Nou motor de patrons del cicle: periovulatori, fase lútia inicial/mitjana, perimenstrual i menstrual.
- Confiança progressiva: senyal inicial (1 cicle), patró emergent (2) i patró recurrent (>=3 amb consistència).
- Detecció de brots multisímptoma respecte de les fases del cicle.
- Les hipòtesis clíniques poden mostrar famílies de possibilitats a valorar amb el professional quan les dades aporten pistes: perfil migranyós/vestibular, modulació pel cicle, processos inflamatoris/autoimmunes, causes endocrines/metabòliques, dolor generalitzat/sensibilització central, perfil pell+digestiu/mastocitari i context de medicació.
- Cada possibilitat explica quines dades l’han activada i què no es pot concloure.
- Les mateixes hipòtesis apareixen als informes i al PDF mèdic.
- Visualització del principal patró del cicle amb una línia temporal relativa a ovulació o menstruació.

## Criteri de seguretat

Paula Tracker no diagnostica. Les opcions de l’apartat Hipòtesis només apareixen si existeix una combinació de dades que les justifica i sempre mostren les limitacions de l’autoregistre. Les estimacions d’ovulació per calendari no es presenten com a confirmades.
