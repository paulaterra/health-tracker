# Paula Tracker v1.4.0

## Anàlisi intel·ligent per apartats

El Dashboard incorpora una fitxa d’anàlisi independent per a dolor, mal de cap, vertígens, digestiu, son, energia, exercici, cicle, pell i medicació.

- Les dades descriptives es mostren quan hi ha registres suficients.
- Les relacions i tendències només apareixen quan el motor supera els llindars mínims.
- Si falten dades, la fitxa indica que l’aplicació encara està aprenent.
- Es manté tot el que ja existia a la v1.3.21.
