# Paula Tracker · v1.6.1

## Canvis

- Les **Possibilitats a valorar amb el professional** mostren noms clínics concrets quan les dades activen el patró: migranya vestibular, trastorns relacionats amb el cicle hormonal, exemples de malalties inflamatòries/autoimmunes, alteracions tiroïdals, fibromiàlgia/sensibilització central i síndrome d’activació mastocitària (MCAS).
- Els noms continuen presentant-se com a **diagnòstics diferencials a comentar**, mai com a diagnòstics ni conclusions de l'app.
- L'apartat **Cicle menstrual** mostra ara la fase actual: fase fol·licular, periovulatòria/ovulació i fase lútia.
- S'ha afegit una targeta explicativa de les fases i dels seus límits estimats segons la dada d'ovulació disponible.
- Si l'ovulació és estimada per calendari, l'app indica explícitament que també ho són els límits entre fases.
