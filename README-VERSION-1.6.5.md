# Paula Tracker v1.6.5

- El registre diari de dolor mostra ara **DOLOR X/10** de manera més explícita al Dashboard i als informes.
- El calendari del Dashboard utilitza tres estats visuals clars: verd, groc i vermell, més gris per als dies sense dades.
- Informes incorpora calendaris de benestar general i per àrea: dolor, digestiu, mal de cap, vertígens/boira mental, son, energia i pell.
- Els calendaris també s’inclouen al PDF complet, al resum mèdic PDF i a l’informe mèdic A4.
- L’informe mèdic A4 adapta els calendaris a les categories seleccionades.
- El cicle menstrual no es classifica com a verd/groc/vermell perquè les fases del cicle no impliquen per si soles un estat millor o pitjor.
