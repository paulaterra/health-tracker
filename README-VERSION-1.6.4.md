# Health Track 1.6.4

Ampliació del motor d’hipòtesis clíniques.

- Cada perfil (digestiu, vestibular + cefalea, occipital/cervical, son i cicle) pot mostrar el seu propi bloc de **Possibilitats a valorar amb el professional**.
- Les possibilitats només apareixen quan les dades registrades superen llindars de recurrència o coincidència.
- S’hi mostren noms concrets com SII, SIBO, migranya vestibular, cefalea cervicogènica, apnea del son, SPM/TDPM o endometriosi només quan el patró aporta un motiu mínim per valorar-los.
- Es mantenen separades les dades que activen una possibilitat i els límits del que l’app no pot concloure.
- Els brots multisímptoma mantenen el motor transversal per fibromiàlgia/sensibilització central, MCAS, alteracions tiroïdals, causes inflamatòries/autoimmunes, modulació hormonal i medicació.
- El sistema continua sent determinista i no diagnòstic: no inventa una malaltia a partir d’un únic símptoma.
