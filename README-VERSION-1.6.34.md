# v1.6.34

- La vista professional incorpora «Vista prèvia» als documents compatibles.
- Els PDF, les imatges PNG/JPG/WebP i els fitxers de text es poden consultar dins l’app sense descarregar-los.
- La previsualització s’obre en una finestra gran i conserva també l’opció de descàrrega.
- Els formats que el navegador no pot mostrar directament, com DOC o DOCX, mantenen l’opció «Descarrega».
