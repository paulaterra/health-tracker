# Paula Tracker — Intel·ligència V4

Aquesta versió conserva Supabase, PWA, la interfície actual i tots els formularis.

## Millores afegides

- Hipòtesis només a partir de 14 dies amb dades.
- Confiança basada en força, mostra, cobertura temporal i estabilitat entre períodes.
- Detecció de brots multisimptomàtics de dos o més dies.
- Perfil del dolor per zones: freqüència, intensitat mitjana, pic i possibles relacions amb son, cicle, exercici i digestió.
- Finestra premenstrual automàtica dels cinc dies previs a cada inici de regla registrat.
- Ovulació registrada incorporada al motor de patrons.
- Anàlisi temporal preliminar de medicació quan hi ha dolor abans i després d'almenys tres preses comparables.
- Resultats integrats al Dashboard, Patrons, Conclusions i Informes.

Les associacions no demostren causalitat ni substitueixen una valoració mèdica.
