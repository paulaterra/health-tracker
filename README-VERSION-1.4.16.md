# Paula Tracker v1.4.16

## Correcció del resum diari

- El **Resum per apartats** mostra ara exclusivament els registres del dia seleccionat.
- Els episodis de **Pell** ja no es repliquen automàticament en dies posteriors pel fet de continuar oberts.
- Un episodi de pell apareix al resum només en la seva data de registre (`dataInici`).
- L’anàlisi intel·ligent de 30, 60 o 90 dies continua utilitzant l’historial complet.
