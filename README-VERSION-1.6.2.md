# Health Track · v1.6.2

## Canvis

- El registre de **Cicle menstrual** permet marcar manualment, per a cada dia, **Fase fol·licular**, **Ovulació** o **Fase lútia**.
- La menstruació continua registrant-se amb el control **Tinc la regla**.
- S'ha eliminat de la interfície el registre de **finestra fèrtil**, perquè no és necessari per a l'objectiu de Health Track.
- Quan marques **Ovulació**, la data del registre es desa com a ovulació i pots indicar la font (manual, Clue, test LH, temperatura basal o altres).
- Les fases marcades manualment tenen prioritat sobre les estimacions automàtiques. Si no marques una fase, Health Track pot inferir-la orientativament a partir de la menstruació i l'ovulació.
- El calendari detallat diferencia **fase fol·licular, ovulació registrada, fase lútia i menstruació**.
- El motor continua utilitzant internament una finestra periovulatòria de ±3 dies per detectar patrons, però ja no es presenta com a finestra fèrtil.
