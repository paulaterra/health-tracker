# Preview — Patrons V2

Aquesta còpia completa serveix per provar en local la nova lògica de patrons abans de publicar-la.

Canvis principals:
- patrons temporals i seqüències amb més prioritat;
- anàlisi específica respecte al cicle menstrual;
- menys correlacions espúries i duplicades;
- factors protectors restringits a factors plausiblement modificables;
- informe més selectiu i amb llenguatge més prudent;
- conserva les correccions prèvies de navegació del resum diari i passos.

Per provar-ho: obre la carpeta amb Visual Studio Code i executa `index.html` amb Live Server.
